# LinkedIn Job Assistant

> 🇬🇧 Повна документація (встановлення, налаштування, усі команди) — в
> англійському [README.md](README.md). Ця сторінка — огляд проєкту українською.

Локальний помічник у пошуку роботи: стежить за повідомленнями рекрутерів у
вашій скриньці LinkedIn, шукає вакансії на DOU, Djinni, Jooble та LinkedIn,
оцінює їх відповідність вашому резюме і готує чернетки відповідей та
супровідних листів. **Сам нічого не надсилає** — останній клік завжди за вами.

![Дашборд — вакансії, відсортовані за релевантністю](docs/dashboard.png)

## Що вміє

**1. Асистент скриньки** — читає непрочитані повідомлення LinkedIn, оцінює
кожне за вашим профілем навичок, готує чернетку відповіді мовою співрозмовника
(🇺🇦/🇷🇺/🇬🇧) і підказує, коли варто прикріпити резюме. Чернетки — це markdown-файли
у `drafts/`; кнопку «Надіслати» він не натискає ніколи.

**2. Пошук вакансій** — DOU (офіційний RSS), Djinni (публічна дошка, без
логіна), Jooble (офіційний API), LinkedIn Jobs (помірний скрейпінг, раз на
день, вимикається). Одна й та сама вакансія з різних дощок склеюється в одну
картку. Для сильних збігів готується пакет: супровідний лист мовою вакансії +
посилання + шлях до резюме.

**3. Дашборд** — усі вакансії на одній сторінці, відсортовані за релевантністю:
конвеєр статусів **New → Viewed → Applied**, приватні нотатки, пошук,
мультифільтри за статусом/джерелом/балом, підсвітка нових з останнього візиту.
Стан зберігається на диску і переживає перезапуск браузера чи системи.

**4. Автоматизація** — усе крутиться локально через launchd: скринька
перевіряється щогодини, DOU — щогодини, LinkedIn — раз на день. Значок на
іконці в Dock показує кількість непрочитаних тредів LinkedIn + Djinni, а
щоденне нагадування підказує, де після відгуку тиша 7+ днів.

## Ключові принципи

- 🔒 **Безпека:** пароль ніде не зберігається (логінитесь один раз самі),
  все працює локально.
- 🚫 **Жодної автовідправки:** скрипти лише готують — переглядаєте і
  надсилаєте ви.
- ⚖️ **Мінімальний ризик:** DOU — легальний RSS, Djinni — публічна сторінка,
  Jooble — офіційний API, LinkedIn — помірно і з можливістю вимкнути.

## Швидкий старт

```bash
cd ~/linkedin-assistant
npm install && npx playwright install chromium
node login.mjs        # логінитесь самі (з 2FA), сесія зберігається локально
node jobs.mjs         # знайти вакансії та зібрати пакети
node dashboard.mjs --open
```
