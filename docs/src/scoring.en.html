How a vacancy gets scored

Every vacancy passes two gates. First a free local keyword score built from skills.json, then Claude rates the fit against your resume from 0 to 100. An application package is written only when both gates pass.

Special cases

No description

Under 300 characters of text, the vacancy is scored on its title. The first rejection does not mark it seen, so the next run re-reads it with the description. The second rejection is final.

Claude did not answer

The call is retried once. If it fails again, the package is written on keyword points alone so the match is not lost.

Per-board threshold

dou.minScore, djinni.minScore and linkedin.minScore override the global one. None is set today, so all use 18.

LinkedIn messages

Same points, different thresholds: ≥ 8 is relevant, ≥ 4 is maybe. They decide whether a reply draft is written.
